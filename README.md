# STM32F103C6T6 Projects
This repository contains my STM32 Embedded C projects developed while learning ARM Cortex-M microcontrollers.
The projects focus on register-level programming and understanding peripheral interfaces.

## Topics Covered
- GPIO
- LED Patterns
- Push Buttons
- 7 Segment Displays
- Keypads
- LCD Interfacing
- Interrupts
- Timers
- Counters
- PWM
- ADC

## Tools Used
- STM32F103C6
- Keil uVision
- STM32CubeIDE
- Proteus

## Why I Built This
After learning PIC microcontrollers, I moved to STM32 to understand ARM-based embedded systems. These projects helped me gain hands-on experience with peripherals, registers, and embedded programming concepts used in industry.
